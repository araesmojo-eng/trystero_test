# WebRTC (Web Real-Time Communication) Test Using Trystero

Test of the WebRTC [Trystero project](https://trystero.dev/)

Simple test app using birds that randomize based on user entering the room with objects that can be dropped.

Tests ability of multiple users to log onto a room instance and view the actions of other users.

Can be tried at [Trystero Test Live](https://araesmojo-eng.github.io/trystero_test/)
